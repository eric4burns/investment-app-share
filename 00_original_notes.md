Not sure what else needs to be researched.

## Items the app should have
1. Be able to pull account values and positions from Fidelity.
2. Be able to make charts of returns over different time periods.
3. Be able to compare other performance metrics on the same plot (S&P).
4. Be able to do custom charting like TradingView.
5. Pull in X posts from certain follows specific to stocks of interest.
6. Watch list of different stocks/ETFs and organization.
7. Be able to place theoretical trades in a theoretical account, to test different approaches and algorithms.
